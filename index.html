画像圧縮ツールの使い方

  1. 画像を追加 — 点線のエリアにドラッグ＆ドロップ、またはクリックしてファイルを選択します。複数枚をまとめて追加できます。
  2. 品質を調整 — スライダーで品質を決めます。既定の80%は「見た目の違いがほとんど分からない」水準で、容量を大きく削減できる目安です。
  3. ダウンロード — 各カードの「ダウンロード」を押すと、圧縮後の画像が保存されます。「すべてダウンロード」でまとめて保存することもできます。

なぜ画像圧縮が必要なのか

画像はWebページの容量の大部分を占める要素です。写真をそのまま掲載すると、ページの表示が遅くなり、 閲覧者の離脱や検索エンジンでの評価低下につながることがあります。目安として、写真は1枚あたり100〜300KB程度に 収めておくと、表示速度と画質のバランスが取りやすくなります。

また、メール添付やフォームのアップロードには容量制限が設けられていることが多く、 「ファイルサイズが大きすぎます」と弾かれてしまう原因のほとんどは画像の解像度と品質です。 本ツールで事前に圧縮しておけば、そうしたトラブルを避けられます。

形式ごとの特徴

形式圧縮方式透過向いている用途
JPEG非可逆不可写真・スクリーンショット以外の自然画像。もっとも互換性が高い。
PNG可逆可ロゴ・アイコン・図表など、輪郭や文字を劣化させたくない画像。
WebP可逆／非可逆可Web掲載全般。JPEGより小さく、透過も扱えるため第一候補になる。

プライバシーについて

多くのオンライン圧縮サービスは、画像を一度サーバーへ送信して処理します。本ツールはそれを行いません。 ファイルの読み込み・縮小・再エンコード・保存はすべて、お使いのブラウザに搭載された Canvas API を用いて端末内で実行されます。社外秘の資料や個人情報を含む画像でも、 外部に送信される心配なく処理できます。オフライン状態でも動作します。

よくある質問

画像はサーバーに送信されますか？
いいえ。読み込みから保存まで、すべてブラウザ内で完結します。ネットワークへ画像が送られることはありません。
圧縮すると画質は悪くなりますか？
JPEG・WebPは非可逆圧縮のため、品質を下げるほど劣化しますが、80%前後なら多くの場合で違いは判別しにくいレベルです。PNGは可逆圧縮なので、品質設定を変えても画質は変わりません（容量削減効果も限定的です）。透過PNGを大きく軽くしたい場合は、出力をWebPにすると効果的です。
何枚まで一度に処理できますか？
回数制限はありませんが、枚数と解像度の分だけメモリを消費します。非常に大きな画像を数十枚同時に処理すると動作が重くなるため、その場合は数回に分けてください。
元のファイルは変更されますか？
いいえ。元のファイルには一切手を加えません。圧縮後の画像は別ファイルとしてダウンロードされます。
